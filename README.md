# 🩺 CareSync

CareSync is a digital healthcare platform that simplifies medical information and centralizes family health management into one secure, intelligent system.

---

## Problem Statement

Many families struggle with:
- Missed medication schedules
- Lack of centralized patient health records
- Poor understanding of medical conditions
- Inefficient appointment and queue management
- Manual record-keeping leading to data loss

---

## 🛠 Technologies Used

### Frontend
- Next.js
- TypeScript
- Tailwind CSS
- ShadCN UI

### Backend
- Next.js API Routes
- Node.js
- MongoDB / PostgreSQL
- phi3:mini (local)
