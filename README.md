# 🩺 CareSync

CareSync is a digital healthcare platform that simplifies medical information and centralizes family health management into one secure, intelligent system.

---

## Problem Statement

Many families struggle with:
- Confusing medical reports filled with complex terminology
- Scattered prescriptions and lab results
- Missed medication schedules
- Lack of centralized family health records
- Poor understanding of medical conditions

---

## 🛠 Technologies Used

### Frontend
- Next.js
- TypeScript
- Tailwind CSS
- ShadCN UI

### Backend
- Next.js API Routes
- Node.js
- MongoDB / PostgreSQL
